
# 1 Definition

Ein Algorithmus ist ein allgemeines, eindeutiges Verfahren zur Lösung
einer Klasse gleichartiger Probleme, gegeben durch einen aus
elementaren Anweisungen bestehenden Text.

Ein Algorithmus ist eine eindeutige Handlungsvorschrift zur Lösung
eines Problems oder einer Klasse von Problemen.

# 2 Darstellung von Algorithmen

• Aufbau: Name des Algorithmus, Parameterliste, Anweisungen
• zulässige Wertebereiche der Ein- und Ausgabe angeben, meist mathematische Notation
• Typ und Wertebereich sonstiger Variablen ergeben sich aus dem Kontext
• Wertzuweisungen ← (aber nicht =, das wird in Pseudo-Code für Vergleich benutzt )
• Schleifen/Sprünge for while do repeat goto (return)
• Bedingungen/Verzweigungen if then else endif
• Pseudo-Code beschreibt den Vorgang implementierungsunabhängig, d.h. man
kann ihn in jeder Sprache nachbauen

# 3 Verifikation


Was ist Verifikation?
• Überprüfung/Nachweis, dass der Algorithmus macht, was er verspricht
• formale Verifikation (Beweis)
• praktische Verifikation (Tests)

## 3.1 Formale Verifikation

• präziser Nachweis erfordert präzise Spezifikation
• für kleine Programmteile z.T. automatisiert möglich
• für größerer Programme schwierig / unmöglich (praktische Grenzen/Gödel))
• mathematisches Beweisen: Prämissen -> logische Schlußfolgerungen -> Schluß
• bei Algorithmen viel Aussagenlogik
