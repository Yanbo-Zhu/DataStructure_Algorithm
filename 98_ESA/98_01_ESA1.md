Gibt es eine bessere Lösung für den unsortierten Fall, welche Zeitkomplexität hat sie?

![[98_ESA/image/Pasted image 20241115170729.png]]

```c
SumOfTwo_advanced(A,n)
for c ← 1 to n // pick next candidate
	if A[c] = 0 // check for zero, because then…
		return TRUE // …there will always be a sum

for c ← 1 to n // pick next candidate
	c_is_sum ← FALSE // assume c has no summands
	for a ← 1 to n // all numbers for first summand
		for b ← a to n // only needed numbers for second summand
			if A[c] = A[a] + A[b] // test sum
				c_is_sum ← TRUE // confirmed!
	if not c_is_sum // we really found no sum for c
		return FALSE // we’re done

return TRUE // all candidates were sums, also done
```

## 3.5 e: Gibt es effizientere Lösungen
Gibt es effzientere Lösungen? Wenn Ja, geben Sie den Algorithmus an, wenn nein, begründen Sie dies.
Antwort:   Ja, ein iterativer Ansatz mitO(n) ist effizienter:

```
def find_min(A):
	min_value = A[0]
	for i in range(1, len(A)):
		   if A[i] < min_value:
			   min_value = A[i]

	return min_value
```
